Interação com o ChatGPT (GPT-5)

Durante o desenvolvimento deste projeto, parte da lógica e da estrutura de código foi elaborada com o auxílio do ChatGPT (modelo GPT-5), utilizado como ferramenta de apoio técnico e de documentação.

Nesta conversa, o objetivo foi ajustar o código para rodar integralmente no ambiente do Google Colab, eliminando a necessidade de montar o Google Drive durante a inicialização. A interação envolveu:

Simplificação da estrutura de diretórios e arquivos locais.

Adaptação do código para funcionar de forma autônoma no Colab.

Ajustes na manipulação de estados, threads e arquivos pickle.

Eliminação de dependências externas do Drive, mantendo a execução local e reprodutível.

Essa colaboração seguiu boas práticas de documentação, modularização e portabilidade de notebooks científicos, contribuindo para uma versão mais leve e acessível do projeto.
